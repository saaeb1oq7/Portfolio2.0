Project Overview

This project was developed for an industrial training school to provide prospective students with interactive course listings, enrollment forms, and campus information. It emphasizes accessibility and smooth animations across devices.

Technologies Used

  • HTML5 & CSS3 (Flexbox, Grid)
  • Vanilla JavaScript for interactivity
  • Responsive media queries
  • Custom form validation and AJAX

Features

  • Dynamic course filtering
  • Animated scroll effects
  • Contact form with email integration
